# coffeepromo

A small promotional website with a feedback form and basic user data handling.

The project was created as a simple landing page for collecting visitor feedback and storing submitted data through PHP scripts. It includes static HTML/CSS pages, a feedback flow, and server-side form handlers.

## Technologies

- HTML
- CSS
- JavaScript
- PHP

## Running

Place the project on a PHP-enabled web server and open `index.html` in a browser.
